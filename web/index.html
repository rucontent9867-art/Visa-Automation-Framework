           Project File & Directory Reference
        

        
      

      

        

          Quick structural overview of all project directories, report storage, shared screenshot paths, test specs, and configuration files.
        


        

          
          
          

            

              
              /reports
            

            

              Stores generated output report files created automatically after test executions.
            

            
    
              
  • reports/execution-report.html: Standalone interactive dashboard for live test status, summary metrics, and image previews.
    • 
              
  • reports/test-reports.xlsx: Auto-updated Excel workbook organized by execution date sheets with clickable image links.
    • 
            

          


          
          

            

              
              /screenshots
            

            

              Single shared directory for screenshots used by BOTH the HTML report and Excel report.
            

            
    
              
  • Shared Storage: Prevents duplicate image files by serving both HTML and Excel reports from one place.
    • 
              
  • Captured Screenshots: When Screenshot Capture mode is ON, calling captureScreenshot() creates timestamped subfolders: /screenshots/<timestamp>/<spec-name>/<step-name>.png.
    • 
              
  • When Disabled: When Screenshot Capture is OFF, no screenshot files or folders are created.
    • 
            

          


          
          

            

              
              /backups
            

            

              Stores complete timestamped archives created before clearing reports and data.
            

            
    
              
  • Safe Retention: Preserves full copies of data/store.json, reports/execution-report.html, reports/test-reports.xlsx, and all screenshots.
    • 
              
  • Viewable & Restorable: Browse historical HTML reports or inspect manifests via the "View Backups" dialog.
    • 
            

          


          
          

            

              
              /tests/spec
            

            

              Directory containing all Playwright test specification files.
            

            
    
              
  • Contains end-to-end automation scripts that execute Playwright test flows and assertions.
    • 
              
  • Utilizes helper methods for screenshot capturing and custom assertions.
    • 
            

          


          
          

            

              
              /tests/assets
            

            

              Storage for media and document assets required during test execution.
            

            
    
              
  • Contains sample applicant photos and document attachments uploaded during form submission tests.
    • 
            

          


          
          

            

              
              /utils
            

            

              Test execution framework utilities and helper functions.
            

            
    
              
  • utils/urlTracker.ts: Automatic URL change listener and explicit tracking utility capturing all navigations, redirects, and payment handoffs.
    • 
              
  • utils/screenshot.ts: Helper utility providing captureScreenshot() for saving step-by-step test evidence.
    • 
              
  • utils/baseTest.ts: Base Playwright test fixture wrapping execution state, retries, URL tracker, and error handling.
    • 
            

          


          
          

            

              
              Configuration Files
            

            

              Project configuration and global settings files.
            

            
    
              
  • test-config.json: Main configuration file controlling target form inputs, concurrency, retries, and screenshot capture toggles.
    •
